4. Blender → glTF → Three.js Pipeline (Tier 1)

Export workflow (Blender 3.6 & 4.2 LTS identical):

  1. Apply/convert curves to mesh; apply modifiers or Apply Modifiers on export.
  2. Scene units = metres; apply scale (Ctrl+A); origin at tile/building base for snapping.
  3. One UV map TEXCOORD_0; Smart UV Project adequate; islands in 0–1.
  4. Materials: Principled BSDF → Base Color / Metallic-Roughness (G=Rough, B=Metal) / Normal (tangent) / Emissive / OCC(R). Flat low-poly: Shadeless/Unlit → KHR_materials_unlit.
  5. Images JPEG (quality 85) preferred (glTF requires PNG/JPEG; exporter converts others slowly).
  6. Characters: ≤4 bone influences/vertex, Use Rest Position Armature, sampling on.

Export settings: Binary .glb, +Y Up, Apply Modifiers on, UVs/Normals on, Tangents off (unless normal maps), Vertex Colors on if used, Draco on for terrain/buildings (static, large) / off for small props (<2k tris — decode CPU > benefit), LOD manual (Decimate 0.5/0.25).

Add-ons (bundled, free): Node Wrangler (Principled Texture Setup from filenames), glTF 2.0 (exporter), LoopTools, Bool Tool, Magic UV.

Third-party (recommended, paid): HardOps + BoxCutter (Superhive/Blender Market), Texel Density Checker (Blender Extensions, free).
