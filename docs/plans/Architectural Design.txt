## 1. Architectural Corrections from Draft 1

1. **Thread Isolation (`SharedArrayBuffer` + Web Worker)**: Running thermodynamic ticks and UI rendering on the same thread causes frame drops during multi-vessel reactions. The simulation loop must run in a dedicated Web Worker at a deterministic 10 Hz tick rate, writing state into a `SharedArrayBuffer` read by the 60 FPS UI thread with zero serialization overhead.
2. **Persistence (`IndexedDB` / OPFS over `localStorage`)**: A chemical world state tracking hundreds of item instances, vessel mixtures, and node depletion timers exceeds `localStorage` limits and stalls frames by 12 to 30 ms per save. State snapshots stream asynchronously from the Worker into **IndexedDB** using LZ4 compression.
3. **Emergent Chemistry over Recipe Lists**: Hardcoding recipes breaks emergent gameplay. The engine below calculates reactions dynamically from **molar mass ($g/\text{mol}$)**, **activation energy ($E_a$)**, **enthalpy of formation ($\Delta H^\circ_f$)**, **solubility product constants ($K_{sp}$)**, and **acid dissociation constants ($\text{p}K_a$)**.

## 3. Stoichiometric & Thermodynamic Chemistry Engine

Instead of scripted item swaps, every substance in the game is defined in a static typed registry (`chem-registry`) and evaluated every tick using the **Arrhenius equation** for reaction rates and **calorimetry** for vessel temperatures:

$$k = A \cdot \exp\left(-\frac{E_a}{R \cdot T}\right)$$

$$T_{\text{new}} = T_{\text{old}} + \frac{-\Delta H_{\text{rxn}} \cdot \Delta \xi + Q_{\text{external}} - Q_{\text{loss}}}{\sum (n_i \cdot C_{p,i}) + m_{\text{vessel}} \cdot C_{p,\text{vessel}}}$$

```typescript
// src/engine/chemistry.ts
export type Phase = 'SOLID' | 'LIQUID' | 'GAS' | 'AQUEOUS';

export interface ChemicalSpecies {
  readonly id: string;               // e.g., 'K2CO3', 'KOH', 'C57H110O6' (Tristearin)
  readonly formula: string;
  readonly molarMass: number;        // g/mol
  readonly density: number;          // g/cm3 at STP
  readonly specificHeat: number;     // J/(g*K)
  readonly meltingPointK: number;
  readonly boilingPointK: number;
  readonly solubility293K: number;   // g per 100g H2O (0 if insoluble)
  readonly pKa?: number;             // Acid dissociation constant
  readonly pKb?: number;             // Base dissociation constant
}

export interface ReactionRule {
  readonly id: string;
  readonly reactants: ReadonlyArray<{ speciesId: string; stoich: number }>;
  readonly products: ReadonlyArray<{ speciesId: string; stoich: number }>;
  readonly activationEnergyJ: number; // Ea (J/mol)
  readonly preExponentialA: number;   // Frequency factor A (1/s)
  readonly enthalpyJPerMol: number;   // dH: negative = exothermic, positive = endothermic
  readonly minpH?: number;
  readonly maxpH?: number;
  readonly requiredCatalystId?: string;
}

export interface VesselState {
  readonly id: string;
  readonly wallMaterial: 'WOOD' | 'RAW_CLAY' | 'FIRED_CERAMIC' | 'COPPER' | 'BOROSILICATE';
  readonly thermalConductivity: number; // W/(m*K) - Wood: 0.15, Ceramic: 1.5, Copper: 398
  readonly failureTempK: number;        // Wood chars at 523K (250°C), Copper melts at 1358K
  readonly volumeLiters: number;
  readonly headSpaceClosed: boolean;    // Required for distillation / gas capture
  temperatureK: number;
  moles: Map<string, number>;           // speciesId -> mole count
}

const GAS_CONSTANT_R = 8.314462; // J/(mol*K)

export function stepVesselThermodynamics(
  vessel: VesselState,
  reactions: ReadonlyArray<ReactionRule>,
  speciesRegistry: ReadonlyMap<string, ChemicalSpecies>,
  ambientTempK: number,
  externalHeatWatts: number,
  dtSeconds: number
): void {
  // 1. Calculate total heat capacity of contents + vessel wall
  let totalHeatCapacityJPerK = 850; // Base vessel heat capacity
  for (const [id, mol] of vessel.moles.entries()) {
    const sp = speciesRegistry.get(id)!;
    totalHeatCapacityJPerK += mol * sp.molarMass * sp.specificHeat;
  }

  let netReactionHeatJ = 0;

  // 2. Evaluate Arrhenius kinetics for all matching reaction rules
  for (const rxn of reactions) {
    let limitingMoles = Infinity;
    for (const r of rxn.reactants) {
      const available = vessel.moles.get(r.speciesId) ?? 0;
      const ratio = available / r.stoich;
      if (ratio < limitingMoles) limitingMoles = ratio;
    }
    if (limitingMoles <= 1e-6) continue;

    // Rate constant k = A * exp(-Ea / (R * T))
    const k = rxn.preExponentialA * Math.exp(-rxn.activationEnergyJ / (GAS_CONSTANT_R * vessel.temperatureK));
    const extentDeltaMol = Math.min(limitingMoles, limitingMoles * (1 - Math.exp(-k * dtSeconds)));

    if (extentDeltaMol > 1e-9) {
      for (const r of rxn.reactants) {
        const current = vessel.moles.get(r.speciesId)!;
        vessel.moles.set(r.speciesId, Math.max(0, current - extentDeltaMol * r.stoich));
      }
      for (const p of rxn.products) {
        const current = vessel.moles.get(p.speciesId) ?? 0;
        vessel.moles.set(p.speciesId, current + extentDeltaMol * p.stoich);
      }
      // Exothermic (dH < 0) adds heat to vessel
      netReactionHeatJ += -rxn.enthalpyJPerMol * extentDeltaMol;
    }
  }

  // 3. Apply external heating & Newtonian cooling to ambient
  const surfaceAreaM2 = 0.12;
  const wallThicknessM = 0.015;
  const heatLossWatts =
    (vessel.thermalConductivity * surfaceAreaM2 * (vessel.temperatureK - ambientTempK)) / wallThicknessM;
  const netHeatJ = netReactionHeatJ + (externalHeatWatts - heatLossWatts) * dtSeconds;

  vessel.temperatureK = Math.max(200, vessel.temperatureK + netHeatJ / totalHeatCapacityJPerK);
}

```

### Exact Physics of the Soap Gameplay Loop

With the engine above, the soap example executes through five physical transformations rather than scripted timers:

1. **Wood Drying (Fickian Diffusion & Latent Heat)**:
* Clicking **Trees -> Hardwood -> White Oak** yields logs with $45\%$ moisture by mass ($1.0\text{ kg}$ cellulose/lignin + $0.82\text{ kg}$ $\text{H}_2\text{O}$).
* Attempting to burn green oak fails because evaporating $0.82\text{ kg}$ of water absorbs $1853\text{ kJ}$ ($\Delta H_{\text{vap}} = 2260\text{ kJ/kg}$), pinning the fire temperature below the $553\text{ K}$ ($280^\circ\text{C}$) pyrolysis threshold of lignin.
* Placing the oak on a drying rack exposes it to ambient vapor pressure deficit ($VPD$). Sleeping 1 day ($24\text{ ticks} = 86,400\text{ simulated seconds}$) reduces moisture to $12\%$, raising the Lower Heating Value (LHV) from $10.2\text{ MJ/kg}$ to $16.8\text{ MJ/kg}$.
* If the player burns **Softwood (Pine)** instead, its high abietic acid/terpene resin content combusts incompletely into carbon soot (lampblack) and pine tar with only $0.4\text{ wt\%}$ potassium, failing to yield usable lye.


2. **Pyrolysis & Calcination ($1050\text{ K}$)**:
* Burning $5.0\text{ kg}$ of seasoned Oak at $1050\text{ K}$ ($777^\circ\text{C}$) leaves $75\text{ g}$ of white wood ash composed of $18\text{ wt\%}$ Potassium Carbonate ($\text{K}_2\text{CO}_3$, $13.5\text{ g} = 0.0977\text{ mol}$), $32\text{ wt\%}$ Calcium Oxide ($\text{CaO}$, $24.0\text{ g} = 0.428\text{ mol}$), and inert silica/phosphates.


3. **Leaching & Double-Displacement Causticization**:
* Dumping $75\text{ g}$ of hardwood ash into a carved Wooden Bucket ($T_{\text{max}} = 523\text{ K}$) with $0.5\text{ L}$ water ($27.75\text{ mol}$ $\text{H}_2\text{O}$) triggers two sequential reactions over the 24-tick sleep cycle:

$$\text{CaO}(s) + \text{H}_2\text{O}(l) \longrightarrow \text{Ca(OH)}_2(aq/s) \quad (\Delta H = -63.7\text{ kJ/mol})$$


$$\text{K}_2\text{CO}_3(aq) + \text{Ca(OH)}_2(aq) \longrightarrow 2\text{KOH}(aq) + \text{CaCO}_3(s)\downarrow$$


* Because Calcium Carbonate ($\text{CaCO}_3$) is insoluble ($K_{sp} = 3.36 \times 10^{-9}$), it precipitates as white chalk sludge at the bottom of the bucket during the 24-tick sleep period, leaving $0.195\text{ mol}$ of dissolved Potassium Hydroxide ($\text{KOH}$) in the supernatant liquid ($\text{pH} = 13.59$).


4. **Decanting & Rendering**:
* Draining the bucket through woven plant fiber separates the aqueous $\text{KOH}$ lye from the $\text{CaCO}_3$ sediment.
* Heating $200\text{ g}$ of raw adipose tissue (from a Medium animal) at $385\text{ K}$ ($112^\circ\text{C}$) melts out $145\text{ g}$ ($0.162\text{ mol}$) of purified Tristearin ($\text{C}_{57}\text{H}_{110}\text{O}_6$) tallow, separating it from collagen cracklings.


5. **Alkaline Hydrolysis (Saponification)**:
* Mixing the $0.162\text{ mol}$ Tristearin with the $0.5\text{ L}$ $\text{KOH}$ solution ($0.486\text{ mol}$ required for exact 1:3 stoichiometry; player must leach 2.5 batches of ash or boil down the lye to increase molarity) at $345\text{ K}$ ($72^\circ\text{C}$) executes:

$$\text{C}_{57}\text{H}_{110}\text{O}_6 + 3\text{KOH} \longrightarrow 3\text{C}_{18}\text{H}_{35}\text{KO}_2\text{ (Soft Potash Soap)} + \text{C}_3\text{H}_8\text{O}_3\text{ (Glycerol)}$$


* **Salting Out (Optional Upgrade)**: Adding crushed Halite ($\text{NaCl}$) swaps the $\text{K}^+$ ion for $\text{Na}^+$ via common-ion precipitation, floating solid hard **Sodium Stearate ($\text{C}_{18}\text{H}_{35}\text{NaO}_2$)** soap curds to the top while leaving glycerol in the bottom brine layer (which can later be nitrated into nitroglycerin).

### Bio-Thermodynamic Energy & Tool Physics

Instead of an arbitrary 1-to-100 stamina bar, the player's body is simulated as a thermodynamic engine with a **Glycogen/Blood Glucose Pool ($0\text{ to }2000\text{ kcal}$)** and an **Adipose Reserve Pool ($15,000\text{ kcal}$ initial)**.

* **Basal & Thermal Drain**:

$$\dot{E}_{\text{total}} = \text{BMR}_{70\text{ kcal/hr}} + \dot{W}_{\text{mechanical}} \cdot \frac{1}{\eta_{\text{human}}} + \max\left(0, \frac{T_{\text{core}} - T_{\text{ambient}}}{0.155 \cdot I_{\text{clo}}}\right)$$



Human muscular efficiency $\eta_{\text{human}}$ is $0.22$ ($22\%$). Starting naked ($I_{\text{clo}} = 0.05$) at night ($285\text{ K} / 12^\circ\text{C}$) triggers shivering thermogenesis that burns an extra $140\text{ kcal/hr}$. Crafting **Tanned Leather Clothes** raises $I_{\text{clo}}$ to $1.15$, cutting cold drain to zero at $12^\circ\text{C}$.
* **Tool Mechanical Advantage Formula**:
Every harvesting action requires overcoming material fracture toughness $G_c$. Equipping a tool from the **Dedicated Tool Menu** modifies energy cost by Mohs hardness ratio and wedge mechanical advantage ($MA = L / t$):

$$E_{\text{action}} = \frac{W_{\text{fracture}}}{MA_{\text{tool}}} \cdot \left(\frac{\text{Mohs}_{\text{target}}}{\text{Mohs}_{\text{tool}}}\right)^2$$



Attempting to chop Oak ($\text{Mohs } 2.2$) with bare hands ($\text{Mohs } 2.5$ fingernail, $MA = 1.0$) is impossible for heartwood and costs $120\text{ kcal}$ for deadfall branches. Equipping a **Hafted Flint Axe** ($\text{Mohs } 7.0$, $MA = 6.5$) drops the cost of felling a full tree to $42\text{ kcal}$.

## 5. Inventory Bootstrapping & The Leather Backpack Pipeline

Because a player cannot carry $15\text{ kg}$ of wet hides, oak bark, and water without a container, the inventory system enforces a strict **3-Tier Spatial Constraint**:

1. **Tier 0 (Unencumbered Start)**:
* **Left & Right Hand Slots**: 2 active carry slots, max $6.0\text{ kg}$ or $1$ bulk item per hand.
* **Stationary Camp Pile**: Unlimited ground storage at coordinates $(0,0)$, exposed to rain (leaches soluble salts, wets firewood) and scavengers (unprotected raw meat spoils or gets stolen at night).


2. **Tier 0.5 (Woven Bark Sling — Optional Bridge)**:
* Stripping fibrous inner bast from Willow or Linden trees and twining it creates a **Bast Fiber Sling** (4 slots, max $8.0\text{ kg}$, $18\text{ durability ticks}$).


3. **Tier 1 (Vegetable-Tanned Leather Backpack)**:
* **Step 1 (Skinning & Fleshing)**: Kill a Medium Animal, equip a knapped **Flint Scraper** in the Tool Menu, and strip the subcutaneous fat from the raw dermis ($45\text{ kcal}$) to halt rapid bacterial putrefaction.
* **Step 2 (Alkaline Dehairing)**: Soak the raw hide in weak wood-ash liquor ($\text{pH } 11.5$) for 12 ticks to swell the collagen fibers and loosen hair follicles, then scrape hair off over a log beam.
* **Step 3 (Tannic Acid Cross-Linking)**: Crush $2.0\text{ kg}$ of White Oak Outer Bark with a hammerstone and steep in $8.0\text{ L}$ water inside a dugout wooden trough to extract $0.08\text{ M}$ Tannic Acid ($\text{pH } 4.2$). Submerge the dehaired hide for 48 ticks (2 days sleep). Tannin polyphenols form hydrogen and covalent bonds across the collagen triple-helix peptides, raising the hydrothermal shrinkage temperature from $335\text{ K}$ ($62^\circ\text{C}$) to $358\text{ K}$ ($85^\circ\text{C}$) and rendering the hide rot-proof.
* **Step 4 (Fat-Liquoring & Stitching)**: Rub rendered animal brain or tallow-soap emulsion into the damp leather so fibers don't dry stiff as rawhide. Pierce seams with a **Bone Awl** and stitch with dried **Deer Sinew** to unlock the **Leather Backpack** (**24 Grid Slots, $40.0\text{ kg}$ max payload, waterproof cover, + 6 Dedicated Tool Belt Quick-Slots**).

* **Settings Best Practices**:

* **Deterministic Save Portability**: "Export Save String" compresses the IndexedDB binary state via `CompressionStream('gzip')` into a Base64 string copied to clipboard; "Import Save" validates the SHA-256 checksum before hydrating state.

The SharedArrayBuffer Bug (You Cannot Put a JS Map in Shared Memory)Draft 2 claimed to use a SharedArrayBuffer for zero-copy thread isolation, then defined moles: Map<string, number> inside VesselState. JavaScript heap objects (Map, strings, arrays) cannot exist inside a SharedArrayBuffer—passing them via postMessage triggers structured-clone serialization and defeats zero-copy memory.The Fix (Fixed-Stride TypedArray Layout): Map all chemical species to static integer indices (0 to 255) and allocate a flat SharedArrayBuffer ($64\text{ KB}$) partitioned into typed views synchronized via Atomics.TypeScript// src/engine/memoryLayout.ts
export const MAX_VESSELS = 32;
export const MAX_SPECIES = 256;

// Total Buffer: 32 vessels * 256 species * 8 bytes (Float64) = 65,536 bytes (64 KB)
// Plus 32 vessels * 8 telemetry floats (tempK, pressurePa, pH, volumeL, etc.) = 2,048 bytes
export const SAB_BYTE_LENGTH = 67584;

export class SharedWorldView {
  public readonly syncFlags: Int32Array;      // 4-byte lock/tick counter for Atomics
  public readonly vesselTelemetry: Float64Array; // Stride 8 per vessel: [tempK, pH, pressureKPa, maxTempK...]
  public readonly vesselMoles: Float64Array;     // Stride 256 per vessel: moles of each species ID

  constructor(sab: SharedArrayBuffer) {
    this.syncFlags = new Int32Array(sab, 0, 16);
    this.vesselTelemetry = new Float64Array(sab, 64, MAX_VESSELS * 8);
    this.vesselMoles = new Float64Array(sab, 64 + MAX_VESSELS * 64, MAX_VESSELS * MAX_SPECIES);
  }

  public getMoles(vesselIndex: number, speciesIndex: number): number {
    return this.vesselMoles[vesselIndex * MAX_SPECIES + speciesIndex];
  }

  public setMoles(vesselIndex: number, speciesIndex: number, moles: number): void {
    this.vesselMoles[vesselIndex * MAX_SPECIES + speciesIndex] = moles;
  }
}
